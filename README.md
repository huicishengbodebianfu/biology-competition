# 生物竞赛各省题目资源库

全国中学生生物学竞赛（联赛）历年真题与配套复习资源的个人收藏库，含国际奥赛与多国官方竞赛真题、章节复习讲义及一个「液态玻璃」风格资源导航站。

> **一句话定位：这是一座"试题库 + 资源地图"，不是一套完整课程。**
> 它把"找题难、找全套题更难"的问题彻底解决了；但"学会生物"仍然要靠你和教材。

## 四、核心方法：真题模考循环

每套真题按下面的闭环使用，一套卷的价值才能榨干：

```text
限时模考 → 批改打分 → 逐题回炉 → 错题归档 → 回归教材 → 二次重做
```

1. **限时模考**：按当年考试通知规定的时长与题型要求（见 `资料\`），打印成纸质卷、手机关机、一气呵成。碎片化刷题 ≈ 白刷。
2. **批改打分**：对照官方答案解析严格给分，记录总分与**各学科得分率**（生化细胞/动植生理/遗传演化/生态行为……）。
3. **逐题回炉**：不只看错题——蒙对的、犹豫超过 1 分钟的都算问题题。每题追问：考点是什么？我卡在哪一步？正确思路的钥匙在哪本教材哪一章？
4. **错题归档**：建一个错题本（纸质或 Anki），按学科分类，标注错误原因：*知识点盲区 / 思维路径错误 / 审题失误 / 时间不够*。
5. **回归教材**：每个暴露的盲区，回到对应章节重读+做章节题。**这一步才是提分的实际发生地。**
6. **二次重做**：3～4 周后只重做标记题，能秒杀才算过关。

**年份使用策略**：
- 由旧到新（2015→2023）滚动练习，感受命题演变；
- **最近两年卷留到考前 1 个月内**做全真模拟，不要提前污染；
- 同一年卷至少间隔一个月再二刷。

## 五、拔高资源怎么用

| 资源 | 题目特点 | 这样用 |
|---|---|---|
| **IBO 理论卷**（`国际奥赛IBO\`） | 长材料分析题为主，信息量大，最贴近联赛改革方向 | 赛前 2-3 个月开始，每周 1 套精做：训练"从陌生材料中提取信息并推理"的能力，而不是追求正确率 |
| **英国 BBO**（`国外竞赛\`） | 材料分析+数据图表解读，强调实验设计思维 | 适合已完成一轮教材的学生；顺便练学术英语阅读 |
| **加拿大多伦多 NBC**（`国外竞赛\`） | 全选择题，覆盖大学普通生物学主干，节奏快 | 适合模考联赛前的"手感训练"，也可用于检验教材阶段成果 |
| **澳大利亚 ASOB** | 计算与推理密度高 | 数理基础好的学生用来拉上限 |

> 英文卷通用技巧：先读题干最后一句（真正问什么）再回头读材料；专业词汇不认识就靠上下文和词根猜——考场上你也只能这么干。

## 七、常见问题

**Q：我不在四川/浙江，初赛卷对我有用吗？**
联赛全国统一卷人人都要考，这部分价值不打折。初赛是省内命题，外省同学参考价值有限，建议去本省学会官网找本省卷。

**Q：答案解析太简略，看不懂怎么办？**
带着具体题号去知乎/贴吧搜"XX年联赛第N题"，或到质心等机构的解析课对照听。把解析看懂的过程本身就是在学知识。

**Q：要不要一开始就刷国外题/IBO？**
不要。它们的知识深度与表述方式是为"已完赛选手"设计的拔高材料，地基没打牢就上会严重打击信心且效率极低。

**Q：实验部分怎么补？**
本库暂无实验资料。理论阶段先用导航站里的虚拟实验/视频建立直观印象；进入省选集训后跟队内实验培训，或参考《生物奥赛实验教程》类书籍。

**Q：PDF 打开乱码/字体缺失？**
导航站使用了方正书宋字体（已随库附带）；试卷 PDF 建议用 Chrome/Edge 浏览器或 Adobe Reader 打开。
