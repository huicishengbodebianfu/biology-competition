# 生物竞赛各省题目资源库

全国中学生生物学竞赛（联赛）历年真题与配套复习资源的个人收藏库，含国际奥赛与多国官方竞赛真题、章节复习讲义及一个「液态玻璃」风格资源导航页。

## 目录结构

| 目录 | 内容 |
|---|---|
| `/`（根目录） | 全国联赛真题 2015–2026：试题 + 答案解析（12 年） |
| `模拟题\` | 省级初赛全卷：四川 2019–2026、浙江 2022（共 18 个 PDF） |
| `国际奥赛IBO\` | IBO 官方理论卷 2017–2024 + 答案（CC BY-NC-SA 授权） |
| `国外竞赛\` | 加拿大多伦多大学 NBC、英国 BBO、澳大利亚 ASO Biology 官方免费真题 39 份 |
| `复习题\` | 章节复习讲义（细胞信号转导、光合作用等课件） |
| `资料\` | 考试大纲、竞赛章程、实施细则、教材推荐清单、花火生物档案知识库等 |
| `导航\` | `资源.html` 液态玻璃导航站：18 大分类站点导航 + 本地资料速览 + 可达性测试 |
| `来源.txt` | 全部文件的下载出处台账 |

## 统计

- 合计 **116 个** 收录文件（另有解压出的知识库子目录），约 300 MB
- 真题覆盖：中国联赛 12 年 · 四川初赛 8 年 · 浙江 1 年 · IBO 8 年 · 加拿大 NBC 8 年 · 英国 BBO 6 年 · 澳大利亚 ASOB 9 年

## 使用

浏览器打开 `导航\资源.html` 即可使用导航站（亮/暗主题、站点过滤、镜像可达性测试、粒子交互）。
